# Python turtle 海龟绘图知识点速查

## 一、基本导入与画布设置

- `import turtle`：导入 turtle 库。
- `turtle.setup(width, height)`：设置画布大小。
  - 参数为整数：表示像素值，如 `turtle.setup(800, 600)`。
  - 参数为小数（0~1 之间）：表示占屏幕尺寸的比例，如 `turtle.setup(0.5, 0.6)` → 宽度占屏幕 50%，高度占屏幕 60%，**不是 0.5 像素**。
- `turtle.bgcolor("颜色名")`：设置画布背景色，如 `turtle.bgcolor("skyblue")`。

## 二、画笔速度控制

- `turtle.speed(速度值)`：范围 0~10。
  - `0`：最快（无动画效果，瞬间完成）。
  - `1`：最慢。
  - `10`：较快，但不是最快。
- **记忆**：想最快用 `speed(0)`，想最慢用 `speed(1)`。

## 三、画笔控制（落笔/抬笔/粗细/颜色）

| 函数 | 作用 | 易错提醒 |
|------|------|----------|
| `turtle.pendown()` | 落笔，移动时画线 | 忘记调用 → 画不出图形 |
| `turtle.penup()` | 抬笔，移动时不画线 | 画完后忘记落笔 |
| `turtle.pensize(粗细)` | 设置画笔粗细（像素） | `width(4)` 也可用，推荐 `pensize()` |
| `turtle.pencolor("颜色")` | 设置画笔颜色 | 与 `fillcolor`、`bgcolor` 区分 |
| `turtle.fillcolor("颜色")` | 设置填充颜色 | 需配合 `begin_fill()` / `end_fill()` |
| `turtle.color("画笔色", "填充色")` | 同时设置画笔和填充色 | 第一个参数为画笔色 |

## 四、运动与绘制

### 1. 移动与转向
- `turtle.forward(距离)`：向前移动。
- `turtle.backward(距离)`：向后移动。
- `turtle.left(角度)`：左转（改变方向，不移动）。
- `turtle.right(角度)`：右转（改变方向，不移动）。
- `turtle.goto(x, y)`：移动到绝对坐标 (x, y)，**海龟方向不变**（车开过去，车头朝向不变）。
- `turtle.home()`：回到原点 (0,0)，并将方向重置为初始方向（向右）。不擦除图形。

### 2. 画圆（`circle` 完整参数）
- `turtle.circle(radius, extent=None, steps=None)`
  - `radius`（必填）：半径。**正数→顺时针画圆**，**负数→逆时针画圆**。
  - `extent`（可选）：圆弧角度（度）。默认 `None` 表示 360° 完整圆。例如 `circle(50, 180)` 画半圆。
  - `steps`（可选）：用多边形近似圆的边数。不写为平滑圆。`circle(50, steps=3)` 画等边三角形，`steps=4` 画正方形，`steps=6` 画正六边形。
- **记忆口诀**：正半径顺时钟，负半径逆时针；extent 控制角度，steps 画多边形。

## 五、状态控制与清屏

| 函数 | 擦除图形 | 海龟位置 | 海龟方向 | 显示箭头 | 一级常考点 |
|------|---------|----------|----------|----------|------------|
| `clear()` | ✅ | **不变** | **不变** | 不变 | 只清图，不移动海龟 |
| `reset()` | ✅ | 回到 (0,0) | 重置朝右 | 显示 | 全部重置 |
| `home()` | ❌ | 回到 (0,0) | 重置朝右 | 不变 | 只回家，不擦图 |
| `hideturtle()` | ❌ | 不变 | 不变 | 隐藏 | 只藏箭头 |
| `showturtle()` | ❌ | 不变 | 不变 | 显示 | 显示隐藏的箭头 |

- **特别注意**：
  - `hideturtle()` 只隐藏箭头图标，**不擦除任何图形**。
  - `clear()` 只擦除图形，**海龟位置和方向保持不变**。
  - `reset()` = `clear()` + `home()` + `showturtle()`。

## 七、一级考试易错点汇总（turtle 部分）

| 易错点 | 正确理解 |
|--------|----------|
| `circle(100)` 逆时针？ | 正半径 → **顺时针**画圆；负半径 → 逆时针。 |
| `circle(50, steps=3)` 画什么？ | 画一个半径为 50 的**等边三角形**。 |
| `circle(100, 90)` 画什么？ | 画一个半径为 100、90° 的圆弧（四分之一圆），不是整圆。 |
| `dot(20)` 与 `circle(10)` 区别？ | `dot` 直径 20 的**实心圆**；`circle` 半径 10 的**空心圆**。 |
| `setup(0.5,0.6)` 是 0.5 像素？ | 不是，是屏幕宽度的 50%、高度的 60%。 |
| `speed(0)` 还是 `speed(10)` 最快？ | `speed(0)` 最快，无动画效果。 |
| `pendown()` 和 `pencolor()` 混淆？ | `pendown` 落笔，`pencolor` 设置颜色。 |
| `pensize(4)` 与 `width(4)` 哪个对？ | 两者都正确，功能相同。 |
| `clear()` 会移动海龟吗？ | 不会，只清图，位置方向都不变。 |
| `hideturtle()` 会清空画布吗？ | 不会，只隐藏箭头。 |
| `home()` 会清空画布吗？ | 不会，只回原点重置方向。 |
| `goto(x,y)` 后海龟方向会变吗？ | 不会，方向保持不变。 |
| `right(90)` 是移动吗？ | 不是，只是转向。 |
| 画不出线的原因？ | 可能忘了 `pendown()`，或者使用了 `penup()` 后未落笔。 |
