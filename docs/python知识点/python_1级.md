# Python 一级考试·知识点（不含 turtle）

## 一、Python 基础语法

### 1. 注释
- 单行注释：`#` 开头。
- 多行注释：`""" """` 或 `''' '''`。

### 2. 数据类型
- **int**：整数，如 `7`。
- **float**：浮点数，如 `14.8`。
- **str**：字符串，如 `'中国'`。
- **bool**：`True` / `False`，数值上等价 `1` / `0`。

> **易错**：
> - 赋值 `x = 7` 得到整数类型，不要误认为是浮点数。
> - 取整应使用 `int(a)`，`a/1` 结果仍是浮点数，不取整。
> - `int("7.5")` 会报错（字符串含小数点无法直接转整数），应先用 `float()` 转换。

### 3. 变量与赋值
- 变量无需声明，直接赋值如 `x=7`。
- 变量名区分大小写，不能与保留字冲突。

### 4. 保留字
- 常见：`if`, `else`, `not`, `and`, `or`, `import`。
- 首字母大写时（如 `And`）可作为变量名。

> **易错**：
> - `if` 是保留字，`Break`（大写B）不是保留字。
> - 大小写敏感：`Name`、`And`、`Else`、`Not` 都可以作为变量名。

### 5. 运算符

**算术**：`+ - * / // % **`  
**比较**：`== != > < >= <=`（结果 `True`/`False`）  
**赋值**：`=` `+=` `*=` 等  
**逻辑**：`and` `or` `not`

> **易错**：
> - `/` 结果总是 `float`（如 `10/2=5.0`）。
> - `//` 向下取整（`-7//3=-3`）。
> - `**` 优先级最高，`2**3**2` 从右算。
> - `!=` 不是 `=!`。比较可连写 `a<b<c`。
> - `3 != '3'` 结果为 `True`（类型不同不相等）。
> - `9**2 = 81`，不是 `9`。
> - `5 * (7-3) / 4 = 5.0`，不要误选 `5`（忘记浮点除法）。
> - `3 * 2 ** 3 // 5` 不是从左到右，`**` 优先级最高，先计算 `2**3=8`。

### 6. 类型转换
- `int()`：转换为整数（浮点数截断小数；字符串必须为纯数字，不能带小数点）。
- `float()`：转换为浮点数。
- `str()`：转换为字符串。

> **易错**：
> - 取整用 `int(a)`，不要用 `a/1`（结果仍是 float）或 `a%1`（取小数部分）。
> - `int("123.45")` 会报错，应先用 `float("123.45")` 再 `int()`。
> - `int("12abc")` 也会报错。

### 7. 输入输出
- `print(值1,值2)`，可改 `sep` 和 `end`。
- `input()` 返回字符串，数字需 `int()` 或 `float()` 转换。

> **易错**：考试不支持 `eval()`，一律使用 `int(input())`。

### 8. 字符串
- **不可变**。`+` 拼接，`*` 重复。索引从0开始，`-1` 最后。`len()` 得长度。

> **易错**：
> - 字符串不可变（判断题为正确）。
> - `num='20+6'` 是字符串，不是数值计算结果。

### 9. 条件与循环
- `if`、`elif`、`else` 后跟冒号，代码块缩进。
- `for i in range(5)`（0~4），`range(1,10,2)` 步长2。
- `while` 注意避免无限循环。

> **易错**：`==` 比较，`=` 赋值。缩进必须一致（4空格）。

### 10. 列表（一级）
- 可变：`append()` 追加，`extend()` 合并，`insert()` 插入。索引/切片同字符串。

## 二、常见编程逻辑

- **整除**：`n // a` 取整除结果，向下取整（如 `10//3=3`）。
- **比较**：`3 != '3'` 为 `True`（类型不同不相等）。

## 三、程序文件与版本

- 后缀 `.py`。Python 2 和 3 不兼容。

## 四、附录：易错知识点汇总（不含 turtle）

| 知识点 | 易错分析 |
|--------|----------|
| **数据类型** | `x = 7` 是 `int`，不是 `float`；`int(9.9)=9`（截断，非四舍五入）；`True+1=2`；`int("7.5")`会报错，必须先用 `float()` 转换 |
| **类型转换取整** | 取整用 `int(a)`，`a/1` 不取整（结果仍是 float），`a%1` 得到小数部分 |
| **字符串转整数** | `int("7.5")` 会报错，必须先用 `float()` 转换 |
| **整数除法** | `/` 结果总是浮点数（`5/2=2.5`，`10/2=5.0`） |
| **整除** | `//` 向下取整（`-7//3=-3`），`100//10=10`，结果不是布尔值 |
| **幂运算优先级** | `2**3**2` 从右计算：`2**(3**2)=512`，不是 `(2**3)**2=64` |
| **运算符优先级** | `3 * 2 ** 3 // 5` 先算 `2**3=8`，再从左到右乘除，不是简单从左到右 |
| **比较运算符** | `!=` 不是 `=!`；`3 != '3'` 结果为 `True`（类型不同不相等） |
| **逻辑运算** | `not b`：若 `b=False`，结果为 `True` |
| **变量赋值顺序** | 变量更新后，后续赋值基于最新值，要逐行跟踪 |
| **字符串不可变** | 字符串一旦创建不能修改，判断题为正确（只能重新赋值） |
| **字符串与数值** | `'20+6'` 是字符串，不是数值结果；`'20' + 6` 会报错 |
| **保留字与变量名** | 保留字小写，大写形式可作为变量名（如 `And`、`Else`） |
| **Python 文件后缀** | `.py`，不是 `.doc` 或 `.python` |
| **缩进错误** | `if` 后的代码块必须缩进，否则报 `IndentationError` |
| **输入转换** | `input()` 返回字符串，数字必须用 `int()` 转换，禁止使用 `eval()` |
