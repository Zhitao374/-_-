 2048 游戏（tkinter 版）分步构建教程

本教程将带领你从零开始，使用 Python 的 tkinter 库逐步构建一个**2048 游戏**。最终游戏支持自定义网格大小（默认 4×4）、方向键控制方块移动与合并、实时分数统计、游戏胜利（达到 2048）与失败（无法移动）检测，以及“新游戏”功能。

整个构建过程分为 **5 个阶段**，每个阶段在前一阶段基础上增加新功能，逻辑清晰，适合初学者或教学使用。

---

## 阶段 1：建立游戏窗口和基础框架

### 目标
创建一个空白窗口，设置标题，并准备游戏类的基本结构。

### 代码
```python
import tkinter as tk           # 1 导入tkinter库

class Game2048:                 # 1 定义游戏类
    def __init__(self, root):   # 1 初始化对象
        self.root = root        # 1 保存主窗口
        self.root.title("2048游戏")  # 1 设置窗口标题

if __name__ == "__main__":      # 1 主入口
    root = tk.Tk()              # 1 创建主窗口
    game = Game2048(root)       # 1 创建游戏对象
    root.mainloop()             # 1 进入事件循环
```

### 讲解
- `tk.Tk()` 创建主窗口。
- `title()` 设置窗口标题。
- `mainloop()` 启动事件循环。
- 定义 `Game2048` 类，将窗口对象保存在 `self.root` 中。

## 阶段 2：创建 4×4 游戏面板（标签网格）

### 目标
- 使用 `Frame` 和 `Label` 构建 4×4 网格，每个单元格初始显示空白。
- 将标签对象存储在二维列表 `self.cells` 中，并实现根据数值刷新背景色的方法。

### 代码（新增 `#2` 部分）
```python
class Game2048:
    def __init__(self, root):
        ...
        self.size = 4                       # 2 定义网格大小
        self.cells = [[None]*4 for _ in range(4)]  # 2 存储标签组件
        self._create_grid()                 # 2 创建网格

    def _create_grid(self):                 # 2 创建4x4标签网格
        frame = tk.Frame(self.root)
        frame.pack(pady=10)
        for i in range(self.size):
            for j in range(self.size):
                label = tk.Label(frame, text="", width=6, height=3,
                                 font=("微软雅黑", 20, "bold"),
                                 bg="white", relief="ridge")
                label.grid(row=i, column=j, padx=2, pady=2)
                self.cells[i][j] = label

    @staticmethod
    def _get_color(val):                    # 2 根据数字返回背景色
        colors = {0:"white", 2:"#eee4da", 4:"#ede0c8", 8:"#f2b179",
                  16:"#f59563", 32:"#f67c5f", 64:"#f65e3b",
                  128:"#edcf72", 256:"#edcc61", 512:"#edc850",
                  1024:"#edc53f", 2048:"#edc22e"}
        return colors.get(val, "#3c3a32")
```

### 讲解
- `self.size` 存储网格边长，方便后续扩展。
- `_create_grid` 创建所有标签，并保存到 `self.cells` 二维列表中。
- `_get_color` 根据数值返回对应的背景色，不同数字显示不同颜色块。
- 此时界面已显示 4×4 空白网格，但还没有数字内容。

## 阶段 3：初始化矩阵数据、随机生成数字并刷新界面

### 目标
- 创建 4×4 的 `self.matrix` 二维数组，初始全 0。
- 实现随机在空白位置生成数字 2（概率 90%）或 4（概率 10%）。
- 实现 `_update_grid()` 根据 `self.matrix` 刷新标签的文字和背景色。
- 游戏开始时调用两次 `_add_random_tile()`，生成两个初始数字。

### 代码（新增 `#3` 部分）
```python
import random                           # 3 导入随机模块

class Game2048:
    def __init__(self, root):
        ...
        self.matrix = [[0]*4 for _ in range(4)]  # 3 初始化4x4矩阵
        self.score = 0                  # 3 初始化得分（暂未使用）
        self._add_random_tile()         # 3 随机生成第一个数字
        self._add_random_tile()         # 3 随机生成第二个数字
        self._update_grid()             # 3 刷新显示

    def _add_random_tile(self):         # 3 在随机空白格生成2或4
        empty = [(i,j) for i in range(self.size) for j in range(self.size) if self.matrix[i][j]==0]
        if empty:
            i,j = random.choice(empty)
            self.matrix[i][j] = 2 if random.random() < 0.9 else 4

    def _update_grid(self):             # 3 根据matrix刷新标签文字和颜色
        for i in range(self.size):
            for j in range(self.size):
                val = self.matrix[i][j]
                self.cells[i][j].config(text=str(val) if val else "",
                                        bg=self._get_color(val))
```

### 讲解
- `self.matrix` 存储每个格子的数值（0 表示空）。
- `_add_random_tile` 收集所有空格坐标，随机选一个放置 2 或 4。
- `_update_grid` 遍历所有标签，更新文字和背景色。
- 此时运行能看到 4×4 网格中有两个数字块，但无法移动。

## 阶段 4：实现方向移动与合并（核心算法）

### 目标
- 绑定键盘方向键事件。
- 实现单行合并函数 `_merge_row`（支持左/右方向）。
- 实现左、右、上、下移动函数，并在移动后添加新数字并刷新界面。
- 使用字典映射按键到动作函数，提高代码可读性。

### 代码（新增 `#4` 部分）
```python
class Game2048:
    def __init__(self, root):
        ...
        self.key_actions = {                # 4 按键动作映射
            "Left": self._move_left,
            "Right": self._move_right,
            "Up": self._move_up,
            "Down": self._move_down,
        }
        self.root.bind("<Key>", self.on_key)   # 4 绑定键盘事件

    def _merge_row(self, row, reverse=False):  # 4 合并一行（左或右）
        """合并一行（从左到右），reverse=True 则从右到左合并，返回新行和分数"""
        tiles = [x for x in row if x != 0]
        if reverse:
            tiles.reverse()

        merged = []
        score_gain = 0
        idx = 0
        while idx < len(tiles):
            if idx+1 < len(tiles) and tiles[idx] == tiles[idx+1]:
                merged.append(tiles[idx]*2)
                score_gain += tiles[idx]*2
                idx += 2          # 合并后跳过下一个
            else:
                merged.append(tiles[idx])
                idx += 1

        merged += [0] * (self.size - len(merged))
        if reverse:
            merged.reverse()
        return merged, score_gain

    def _move_horizontal(self, reverse=False):  # 4 水平移动（左/右复用）
        changed = False
        total_gain = 0
        for i in range(self.size):
            original = self.matrix[i][:]
            new_row, gain = self._merge_row(original, reverse)
            if new_row != original:
                changed = True
                total_gain += gain
                self.matrix[i] = new_row
        self.score += total_gain
        return changed

    def _move_left(self):
        return self._move_horizontal(reverse=False)

    def _move_right(self):
        return self._move_horizontal(reverse=True)

    def _transpose(self):                       # 4 矩阵转置
        self.matrix = [[self.matrix[j][i] for j in range(self.size)] for i in range(self.size)]

    def _move_up(self):                         # 4 上移：转置->左移->转置
        self._transpose()
        changed = self._move_left()
        self._transpose()
        return changed

    def _move_down(self):                       # 4 下移：转置->右移->转置
        self._transpose()
        changed = self._move_right()
        self._transpose()
        return changed

    def on_key(self, event):                    # 4 键盘处理（暂不包含胜负判断）
        action = self.key_actions.get(event.keysym)
        if action and action():
            self._add_random_tile()
            self._update_grid()
            self.score_label.config(text=f"得分: {self.score}")
```

### 讲解
- `_merge_row` 是核心：对一行非零数字进行合并，支持左右方向（通过 `reverse` 参数）。
- `_move_horizontal` 实现左/右移动，复用 `_merge_row`。
- 上/下移动通过转置矩阵转化为水平移动，再转置回来。
- `key_actions` 字典简化了键盘事件处理，便于扩展。
- 移动后自动添加新数字并更新分数显示，此时游戏已可玩，但缺少胜利/失败判定。

## 阶段 5：得分统计、胜利/失败检测、新游戏按钮

### 目标
- 添加得分标签，在移动时累加分数（已在 `_move_horizontal` 中实现）。
- 检测是否出现 2048 方块，弹出胜利提示。
- 检测是否无空格且无相邻相等数字，弹出失败提示。
- 添加“新游戏”按钮，重置游戏。

### 代码（新增 `#5` 部分）
```python
from tkinter import messagebox                  # 5 导入弹窗模块

class Game2048:
    def __init__(self, root):
        ...
        self.victory_triggered = False # 5 记录是否已弹出胜利提示
        self.score_label = tk.Label(root, text="得分: 0", font=("微软雅黑", 14))  # 5 得分标签
        self.score_label.pack()
        tk.Button(root, text="新游戏", command=self.new_game).pack(pady=5)   # 5 新游戏按钮

    def _is_game_over(self):                    # 5 检测是否无法移动
        if any(0 in row for row in self.matrix):
            return False
        for i in range(self.size):
            for j in range(self.size):
                val = self.matrix[i][j]
                if (i+1 < self.size and val == self.matrix[i+1][j]) or \
                   (j+1 < self.size and val == self.matrix[i][j+1]):
                    return False
        return True

    def on_key(self, event):                    # 5 完善键盘处理，加入胜负判定
        action = self.key_actions.get(event.keysym)
        if action and action():
            self._add_random_tile()
            self._update_grid()
            self.score_label.config(text=f"得分: {self.score}")
            if not self.victory_triggered and any(2048 in row for row in self.matrix):
                self.victory_triggered = True
                messagebox.showinfo("胜利", "恭喜你达成2048！")
            if self._is_game_over():
                messagebox.showinfo("游戏结束", f"无法移动。最终得分：{self.score}")
                self.root.destroy()

    def new_game(self):                         # 5 重置游戏
        self.victory_triggered = False
        self.matrix = [[0]*self.size for _ in range(self.size)]
        self.score = 0
        self.score_label.config(text="得分: 0")
        self._add_random_tile()
        self._add_random_tile()
        self._update_grid()
```

### 讲解
- `_is_game_over` 先检查是否有空格，若无则检查相邻是否还有相等数字（可合并），若都没有则游戏结束。
- 每次移动后，若出现 2048 则弹出胜利提示（不强制结束，玩家可继续）。
- 游戏结束时销毁窗口。
- “新游戏”按钮重置矩阵、分数，并重新生成两个初始数字。

## 最终完整代码（面向对象版）

将所有阶段整合，得到完整的可运行 2048 游戏（与 `test.py` 一致）：

```python
import tkinter as tk
from tkinter import messagebox
import random

class Game2048:
    def __init__(self, root, size=4):
        self.root = root
        self.root.title("2048游戏")
        self.size = size
        self.matrix = [[0] * size for _ in range(size)]
        self.cells = [[None] * size for _ in range(size)]
        self.score = 0

        self._create_grid()
        self.score_label = tk.Label(root, text="得分: 0", font=("微软雅黑", 14))
        self.score_label.pack()
        tk.Button(root, text="新游戏", command=self.new_game).pack(pady=5)

        self.key_actions = {
            "Left": self._move_left,
            "Right": self._move_right,
            "Up": self._move_up,
            "Down": self._move_down,
        }
        self.root.bind("<Key>", self.on_key)
        self.new_game()

    def _create_grid(self):
        frame = tk.Frame(self.root)
        frame.pack(pady=10)
        for i in range(self.size):
            for j in range(self.size):
                label = tk.Label(frame, text="", width=6, height=3,
                                 font=("微软雅黑", 20, "bold"),
                                 bg="white", relief="ridge")
                label.grid(row=i, column=j, padx=2, pady=2)
                self.cells[i][j] = label

    def _update_grid(self):
        for i in range(self.size):
            for j in range(self.size):
                val = self.matrix[i][j]
                self.cells[i][j].config(text=str(val) if val else "",
                                        bg=self._get_color(val))

    @staticmethod
    def _get_color(val):
        colors = {0:"white", 2:"#eee4da", 4:"#ede0c8", 8:"#f2b179",
                  16:"#f59563", 32:"#f67c5f", 64:"#f65e3b",
                  128:"#edcf72", 256:"#edcc61", 512:"#edc850",
                  1024:"#edc53f", 2048:"#edc22e"}
        return colors.get(val, "#3c3a32")

    def _add_random_tile(self):
        empty = [(i, j) for i in range(self.size) for j in range(self.size) if self.matrix[i][j] == 0]
        if empty:
            i, j = random.choice(empty)
            self.matrix[i][j] = 2 if random.random() < 0.9 else 4

    def _merge_row(self, row, reverse=False):
        tiles = [x for x in row if x != 0]
        if reverse:
            tiles.reverse()
        merged = []
        score_gain = 0
        idx = 0
        while idx < len(tiles):
            if idx+1 < len(tiles) and tiles[idx] == tiles[idx+1]:
                merged.append(tiles[idx]*2)
                score_gain += tiles[idx]*2
                idx += 2          # 合并后跳过下一个
            else:
                merged.append(tiles[idx])
                idx += 1
        merged += [0] * (self.size - len(merged))
        if reverse:
            merged.reverse()
        return merged, score_gain

    def _move_horizontal(self, reverse=False):
        changed = False
        total_gain = 0
        for i in range(self.size):
            original = self.matrix[i][:]
            new_row, gain = self._merge_row(original, reverse)
            if new_row != original:
                changed = True
                total_gain += gain
                self.matrix[i] = new_row
        self.score += total_gain
        return changed

    def _move_left(self):
        return self._move_horizontal(reverse=False)

    def _move_right(self):
        return self._move_horizontal(reverse=True)

    def _transpose(self):
        self.matrix = [[self.matrix[j][i] for j in range(self.size)] for i in range(self.size)]

    def _move_up(self):
        self._transpose()
        changed = self._move_left()
        self._transpose()
        return changed

    def _move_down(self):
        self._transpose()
        changed = self._move_right()
        self._transpose()
        return changed

    def _is_game_over(self):
        if any(0 in row for row in self.matrix):
            return False
        for i in range(self.size):
            for j in range(self.size):
                val = self.matrix[i][j]
                if (i + 1 < self.size and val == self.matrix[i + 1][j]) or \
                   (j + 1 < self.size and val == self.matrix[i][j + 1]):
                    return False
        return True

    def on_key(self, event):
        action = self.key_actions.get(event.keysym)
        if action and action():
            self._add_random_tile()
            self._update_grid()
            self.score_label.config(text=f"得分: {self.score}")
            if any(2048 in row for row in self.matrix):
                messagebox.showinfo("胜利", "恭喜你达成2048！")
            if self._is_game_over():
                messagebox.showinfo("游戏结束", f"无法移动。最终得分：{self.score}")
                self.root.destroy()

    def new_game(self):
        self.matrix = [[0] * self.size for _ in range(self.size)]
        self.score = 0
        self.score_label.config(text="得分: 0")
        self._add_random_tile()
        self._add_random_tile()
        self._update_grid()

if __name__ == "__main__":
    root = tk.Tk()
    Game2048(root)
    root.mainloop()
```

## 总结

通过以上 5 个阶段，你从零开始构建了一个完整的 2048 游戏，学习了：
- tkinter 标签（Label）、键盘事件绑定
- 二维数组的矩阵操作与变换（转置、反转）
- 合并算法的统一实现（`_merge_row` 支持左/右方向）
- 得分统计与胜利/失败判定
- 使用字典映射按键动作，提高代码可维护性

修改 `self.size` 即可调整游戏难度（例如 5×5 或 6×6），更大棋盘需要更长的合并时间，挑战性更高。祝你编程愉快！
