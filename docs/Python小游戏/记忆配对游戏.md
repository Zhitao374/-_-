# 记忆配对游戏（tkinter 版）分步构建教程

本教程将带领你从零开始，使用 Python 的 tkinter 库逐步构建一个**记忆配对（翻牌配对）**游戏。最终游戏支持自定义行列数（如 4×8）、随机生成水果图标对、点击配对、延迟翻回、胜利检测等功能。

整个构建过程分为 **5 个阶段**，每个阶段在前一阶段基础上增加新功能，逻辑清晰，适合初学者或教学使用。

---

## 阶段 1：建立游戏窗口和基础框架

### 目标
创建一个空白窗口，并设置标题。

### 代码
```python
import tkinter as tk # 1 导入tkinter库

class MemoryGame:    # 1 定义记忆配对游戏类
    def __init__(self, root): # 1 初始化游戏对象
        self.root = root # 1 初始化主窗口对象

if __name__ == "__main__":  # 1 主函数入口
    root = tk.Tk()  # 1 创建主窗口对象
    game = MemoryGame(root) # 1 创建游戏对象
    root.mainloop() # 1 进入主事件循环
```

### 讲解
- `import tkinter as tk`：导入 tkinter 库，并给它一个简短的别名 `tk`，方便调用。
- `tk.Tk()`：创建应用程序的主窗口（根窗口），所有组件都放在这个窗口里。
- `root.title("记忆配对游戏")`：设置窗口标题栏显示的文字。
- `root.mainloop()`：启动 tkinter 的事件循环，让窗口保持显示并响应用户操作（如点击、按键）。没有这一行，窗口会一闪而过。
- 类的定义 `class MemoryGame:`：用面向对象的方式组织代码，把数据和函数封装在一起，便于管理。
- `__init__` 方法：类的构造函数，在创建对象时自动调用，用于初始化属性（比如把 `root` 保存到 `self.root` 中）。
- `self` 参数：代表实例自身，通过 `self.xxx` 可以在类的方法之间共享数据（如 `self.root` 可以在其他方法中使用）。
- `if __name__ == "__main__":`：确保当直接运行此脚本时才执行下面的代码，防止被其他文件导入时自动运行。

## 阶段 2：创建按钮网格

### 目标
在窗口中生成一个 4 行 × 8 列的按钮网格，所有按钮显示问号 `?`。

### 代码（在 `mainloop` 之前添加）
```python
import tkinter as tk # 1 导入tkinter库

class MemoryGame:    # 1 定义记忆配对游戏类
    def __init__(self, root, rows=4, cols=8, fruits=None): # 1 初始化游戏对象
        self.root = root # 1 初始化主窗口对象
        self.rows = rows # 2 初始化行数
        self.cols = cols # 2 初始化列数
        self.root.title("记忆配对游戏") # 2 设置窗口标题
        ...
        self.create_board() # 2 创建游戏板

    def create_board(self): # 2 创建游戏板
        frame = tk.Frame(self.root) # 2 创建游戏板框架
        frame.pack() # 2 放置游戏板框架
        for row in range(self.rows): # 2 创建游戏板行
            for col in range(self.cols): # 2 创建游戏板列
                btn = tk.Button(frame, text="？", width=4, height=2, font=("微软雅黑", 24)) # 2 创建游戏板按钮
                btn.grid(row=row, column=col, padx=2, pady=2) # 2 放置游戏板按钮
```

### 讲解
- `tk.Frame`：一个容器组件，用来放置其他组件（比如按钮），方便布局管理。这里创建了一个 `frame` 来盛放所有卡片按钮。
- `frame.pack()`：使用 pack 布局管理器将 frame 放入窗口中。`pack()` 默认从上到下排列，并自动调整大小。
- 二维列表 `self.buttons`：使用列表推导式 `[[None] * cols for _ in range(rows)]` 创建一个 rows 行、cols 列的列表，用于存储每个按钮对象。这样后续可以通过 `self.buttons[row][col]` 快速访问任意按钮。
- `tk.Button`：创建按钮组件，参数 `text="？"` 设置初始显示文字，`width` 和 `height` 设置按钮大小，`font` 设置字体和字号。
- `grid()` 布局：将按钮按行、列放置到 frame 中。`padx` 和 `pady` 设置按钮之间的水平/垂直间距，使界面更美观。
- 循环嵌套 `for row in range(self.rows): for col in range(self.cols):` 生成所有按钮，确保每个格子都有一个按钮。
- 注意：此时按钮还没有绑定点击事件（`command` 参数为空），所以点击不会有任何反应。这将在阶段 4 中添加。

## 阶段 3：生成随机卡片数据并绑定点击显示图标

### 目标
- 生成随机打乱的水果图标对（共 32 张，16 对）。
- 点击按钮时，将按钮文字临时显示为对应的水果图标。

### 代码（替换阶段2的简单按钮创建，并添加数据生成逻辑）
```python
import random # 3 导入随机库

class MemoryGame:    # 1 定义记忆配对游戏类
    def __init__(self, root, rows=4, cols=8, fruits=None): # 1 初始化游戏对象
        ...
        self.fruits = fruits or ['🍎', '🍌', '🍒', '🍇', '🥝', '🍊', '🍉', '🍓'] # 3 初始化水果列表

        self.buttons = [[None] * cols for _ in range(rows)] # 3 初始化游戏板按钮列表
        self.data = [[0] * cols for _ in range(rows)] # 3 初始化游戏板数据
        ...
        self.new_game() # 3 游戏渲染
        
    def new_game(self): # 3 游戏渲染
        total = self.rows * self.cols # 3 计算游戏板总按钮数
        pairs = total // 2 # 3 计算游戏板配对数
        icon_list = (self.fruits * (pairs // len(self.fruits) + 1))[:pairs] # 3 生成游戏板配对
        cards = icon_list*2 # 3 生成游戏板配对
        random.shuffle(cards) # 3 随机选择游戏板配对

        for row in range(self.rows): # 3 游戏板行
            for col in range(self.cols): # 3 游戏板列
                self.data[row][col] = cards[row*self.cols+col] # 3 设置游戏板数据
                self.buttons[row][col].config(text='？', state=tk.NORMAL) # 3 设置游戏板按钮文本
        
```

### 讲解
- `import random`：导入 Python 的随机数模块，用于打乱卡片顺序。
- `self.fruits`：定义了一个水果图标列表，每种水果对应一个 Emoji 字符。如果用户没有提供自己的列表，则使用默认的 8 种水果。
- 二维列表 `self.buttons` 和 `self.data`：`buttons` 存储按钮对象（用于修改界面），`data` 存储每个格子的水果图标（用于逻辑判断）。
- `new_game()` 方法中的卡片生成逻辑：
  - `total = self.rows * self.cols`：计算总共需要多少张卡片（例如 4×8=32）。
  - `pairs = total // 2`：计算需要多少对（16 对）。
  - `icon_list = (self.fruits * (pairs // len(self.fruits) + 1))[:pairs]`：这是一个巧妙的写法。因为 `pairs` 可能大于水果列表的长度，所以将 `self.fruits` 重复多次，然后截取前 `pairs` 个，得到一个包含 `pairs` 个图标的列表（每个图标只出现一次）。
  - `cards = icon_list * 2`：将刚才的列表复制一遍，使每个图标出现两次（成对）。
  - `random.shuffle(cards)`：随机打乱列表顺序，保证每局游戏卡片位置不同。
- 将一维列表 `cards` 填入二维数组 `self.data`：`cards[row * self.cols + col]` 将线性索引转换为行列索引。
- `self.buttons[row][col].config(text='？', state=tk.NORMAL)`：将按钮文字重置为问号，并设置为可点击状态（`NORMAL`）。
- 注意：阶段 3 还没有实现配对逻辑，点击按钮只会显示图标，不会进行匹配。`command` 绑定将在阶段 4 添加。

## 阶段 4：实现配对逻辑（记录第一张/第二张，成功/失败，延迟翻回）

### 目标
- 记录用户第一次和第二次点击的卡片。
- 如果两张卡片图标相同，则永久保持翻开（禁用按钮）。
- 如果不同，等待 1 秒后自动翻回问号。
- 在动画期间禁止点击其他卡片。

### 代码（替换 `on_click` 函数，并添加状态变量和辅助函数）
```python
class MemoryGame:    # 1 定义记忆配对游戏类
    def __init__(self, root, rows=4, cols=8, fruits=None): # 1 初始化游戏对象
        ...
        self.first = None # 4 初始化第一次点击的按钮
    
    
    def create_board(self): # 2 创建游戏板
        ...
        for row in range(self.rows): # 2 创建游戏板行
            for col in range(self.cols): # 2 创建游戏板列
                btn = tk.Button(frame, text="？", width=4, height=2, font=("微软雅黑", 24) # 2 创建游戏板按钮
                                , command=lambda r=row, c=col: self.on_click(r, c)) # 4 游戏板按钮点击事件
        ...

    def on_click(self, r, c): # 4 游戏板按钮点击事件
        if self.first is None: # 4 如果是第一次点击
            self._reveal_card(r, c) # 4 揭示游戏板按钮
            self.first = (r, c) # 4 设置第一次点击的按钮
        else: # 4 如果是第二次点击
            r1, c1 = self.first # 4 获取第一次点击的按钮
            if (r1, c1) == (r, c): # 4 如果是第一次点击的按钮
                return
            self._reveal_card(r, c) # 4 揭示游戏板按钮
            if self.data[r1][c1] == self.data[r][c]: # 4 如果是配对
                self.buttons[r1][c1].config(state=tk.DISABLED) # 4 禁用游戏板按钮
                self.buttons[r][c].config(state=tk.DISABLED) # 4 禁用游戏板按钮
                self.first = None   # 4 重置第一次点击的按钮
            else:
                # 4 配对失败，延迟翻回
                self.root.after(1000, self._reset_cards, r1, c1, r, c) # 4 存储待翻回的卡片对

    def _reveal_card(self, r, c): # 4 揭示游戏板按钮
        self.buttons[r][c].config(text=self.data[r][c], state=tk.DISABLED) # 4 揭示游戏板按钮

    def _reset_cards(self, r1, c1, r2, c2): # 4 重置游戏板按钮
        """将两张卡片翻回背面"""
        self.buttons[r1][c1].config(text='?', state=tk.NORMAL) # 4 重置游戏板按钮
        self.buttons[r2][c2].config(text='?', state=tk.NORMAL) # 4 重置游戏板按钮
```

### 讲解
- `self.first`：用于记录第一张点击的卡片坐标 `(row, col)`，初始为 `None` 表示还没有翻开任何卡片。
- 在 `create_board` 中，为每个按钮添加了 `command=lambda r=row, c=col: self.on_click(r, c)`。这里使用 `lambda` 并传递默认参数 `r=row, c=col`，是为了让每个按钮记住自己的行列（避免循环结束后变量被覆盖的问题）。
- `on_click` 方法中的逻辑：
  - 如果 `self.first` 为 `None`，表示这是本轮第一次点击：调用 `_reveal_card` 显示图标，并记录坐标。
  - 否则表示已经有一张卡片翻开，取出第一张坐标 `(r1, c1)`。如果第二次点击的是同一张卡片，则直接返回（无效）。
  - 调用 `_reveal_card` 翻开第二张卡片。
  - 判断两张卡片的图标是否相等：
    - 相等（配对成功）：将两张卡片设为禁用（`state=tk.DISABLED`），使其永久保持翻开状态，然后清空 `self.first`。
    - 不相等（配对失败）：使用 `self.root.after(800, self._reset_cards, r1, c1, r, c)` 延迟 0.8 秒后调用 `_reset_cards` 将两张卡片翻回背面。注意这里没有使用 `waiting` 锁，所以快速点击时可能出现三张卡片同时翻开的 bug，这个将在阶段 5 优化。
- `_reveal_card`：将按钮文字改为对应的水果图标，并禁用按钮（防止在动画期间重复点击）。
- `_reset_cards`：将两张卡片的文字改回问号，恢复为可点击状态。
- **注意**：本阶段的代码还没有处理“在延迟期间点击新卡片”的情况，因此快速点击会导致界面混乱。阶段 5 会通过 `pending` 机制修复这个问题。

## 阶段 5：添加胜利检测和新游戏功能

### 目标
- 每次配对成功后检查是否所有卡片都已配对，若是则弹出胜利提示并结束游戏。
- 增加一个“新游戏”按钮，可以重新开始。

### 代码
```python
class MemoryGame:    # 1 定义记忆配对游戏类
    def __init__(self, root, rows=4, cols=8, fruits=None): # 1 初始化游戏对象
        ...
        self.paired_count = 0 # 5 初始化成功配对数
        self.total_pairs = rows * cols // 2 # 5 初始化总配对数
        self.pending = None          # 5 存储待翻回的卡片对 (r1,c1,r2,c2)
        self.pending_id = None       # 5 存储 after 任务的 id，用于取消

    def new_game(self): # 3 游戏渲染
        # 6 取消任何未完成的延迟任务，避免干扰新游戏
        if self.pending_id:
            self.root.after_cancel(self.pending_id)
            self.pending_id = None
        self.pending = None
        ...
        self.first = None # 6 初始化第一次点击的按钮
        self.paired_count = 0 # 6 初始化成功配对数

    def on_click(self, r, c): # 4 游戏板按钮点击事件
        # 5 如果存在等待翻回的卡片对，立即取消并翻回
        if self.pending:
            # 5 取消延迟任务
            if self.pending_id:
                self.root.after_cancel(self.pending_id)
                self.pending_id = None
            # 5 立即翻回 pending 的卡片
            r1, c1, r2, c2 = self.pending
            self._reset_cards(r1, c1, r2, c2)   # 这个方法会设置 self.pending = None
            
        if self.first is None: # 4 如果是第一次点击
            self._reveal_card(r, c) # 4 揭示游戏板按钮
            self.first = (r, c) # 4 设置第一次点击的按钮
        else: # 4 如果是第二次点击
            r1, c1 = self.first # 4 获取第一次点击的按钮
            if (r1, c1) == (r, c): # 4 如果是第一次点击的按钮
                return
            self._reveal_card(r, c) # 4 揭示游戏板按钮
            if self.data[r1][c1] == self.data[r][c]: # 4 如果是配对
                self.buttons[r1][c1].config(state=tk.DISABLED) # 4 禁用游戏板按钮
                self.buttons[r][c].config(state=tk.DISABLED) # 4 禁用游戏板按钮
                self.first = None   # 4 重置第一次点击的按钮
                self.paired_count += 1 # 5 增加成功配对数
                # 5 如果全部配对成功
                if self.paired_count == self.total_pairs:   # 5 如果全部配对成功
                    tk.messagebox.showinfo("胜利", "恭喜你完成了所有配对！") # 5 显示胜利消息
                    self.root.destroy() # 5 销毁主窗口对象 
            else:
                # 4 配对失败，延迟翻回
                self.pending = (r1, c1, r, c) # 5 存储待翻回的卡片对
                # 5 延迟翻回游戏板按钮
                self.pending_id = self.root.after(800, self._reset_cards, r1, c1, r, c) # 5 延迟翻回游戏板按钮
                self.first = None # 5 重置第一次点击的按钮


    def create_board(self):
        ...
        reset_btn = tk.Button(self.root, text="新游戏", command=self.new_game) # 5 创建新游戏按钮
        reset_btn.pack(side=tk.RIGHT, padx=10) # 5 放置新游戏按钮
        
    def _reset_cards(self, r1, c1, r2, c2): # 4 重置游戏板按钮
        ...
        self.pending = None # 5 重置待翻回的卡片对
        self.pending_id = None # 5 重置 after 任务的 id，用于取消延迟任务
```

### 讲解
- `self.paired_count` 和 `self.total_pairs`：用计数器记录已经成功配对的对数。每次配对成功时 `self.paired_count += 1`，当 `self.paired_count == self.total_pairs` 时表示胜利。这种方式比每次遍历整个网格效率更高。
- `self.pending` 和 `self.pending_id`：
  - `self.pending`：存储正在等待翻回的卡片对 `(r1, c1, r2, c2)`。
  - `self.pending_id`：存储由 `after` 返回的任务 ID，以便在需要时取消延迟。
- 在 `on_click` 开头添加了 `if self.pending:` 块：
  - 如果存在等待翻回的卡片对，说明上一轮配对失败且延迟任务尚未执行。
  - 先调用 `after_cancel` 取消原来的延迟任务，然后立即手动调用 `_reset_cards` 将上一对卡片翻回。
  - 这样用户点击新卡片时，上一对会立即翻回，而不会等待 0.8 秒，体验更流畅。
- 配对失败分支中，不再直接调用 `after`，而是保存 `pending` 和 `pending_id`，以便后续打断。
- 新游戏按钮：在 `create_board` 中添加了一个“新游戏”按钮，绑定 `self.new_game` 方法。使用 `pack(side=tk.RIGHT, padx=10)` 将按钮放在右下角。
- `new_game` 方法的增强：
  - 如果存在未完成的延迟任务（`self.pending_id` 不为 `None`），先取消它，避免旧任务干扰新游戏。
  - 清空 `self.pending`，重置 `self.first` 和 `self.paired_count`，然后重新生成卡片。
- 胜利检测：配对成功后检查 `self.paired_count == self.total_pairs`，若是则弹出消息框并销毁窗口。
- 这些改进使游戏更加健壮，允许用户在延迟期间打断并立即开始新一轮配对，同时支持随时重置游戏。

## 最终完整代码（面向对象版）

将所有阶段整合并封装为类，即为下面完整的可运行游戏：

```python
import tkinter as tk # 1 导入tkinter库
import random # 3 导入随机库

class MemoryGame:    # 1 定义记忆配对游戏类
    def __init__(self, root, rows=4, cols=8, fruits=None): # 1 初始化游戏对象
        self.root = root # 1 初始化主窗口对象
        self.rows = rows # 2 初始化行数
        self.cols = cols # 2 初始化列数
        self.fruits = fruits or ['🍎', '🍌', '🍒', '🍇', '🥝', '🍊', '🍉', '🍓'] # 3 初始化水果列表
        self.root.title("记忆配对游戏") # 2 设置窗口标题

        self.buttons = [[None] * cols for _ in range(rows)] # 3 初始化游戏板按钮列表
        self.data = [[0] * cols for _ in range(rows)] # 3 初始化游戏板数据
        self.first = None # 4 初始化第一次点击的按钮
        self.paired_count = 0 # 5 初始化成功配对数
        self.total_pairs = rows * cols // 2 # 5 初始化总配对数
        self.pending = None          # 5 存储待翻回的卡片对 (r1,c1,r2,c2)
        self.pending_id = None       # 5 存储 after 任务的 id，用于取消

        self.create_board() # 2 创建游戏板
        self.new_game() # 3 游戏渲染

    def create_board(self): # 2 创建游戏板
        frame = tk.Frame(self.root) # 2 创建游戏板框架
        frame.pack() # 2 放置游戏板框架
        for row in range(self.rows): # 2 创建游戏板行
            for col in range(self.cols): # 2 创建游戏板列
                btn = tk.Button(frame, text="？", width=4, height=2, font=("微软雅黑", 24) # 2 创建游戏板按钮
                                , command=lambda r=row, c=col: self.on_click(r, c)) # 4 游戏板按钮点击事件
                btn.grid(row=row, column=col, padx=2, pady=2) # 2 放置游戏板按钮
                self.buttons[row][col] = btn # 3 初始化游戏板按钮列表
        
        reset_btn = tk.Button(self.root, text="新游戏", command=self.new_game) # 6 创建新游戏按钮
        reset_btn.pack(side=tk.RIGHT, padx=10) # 6 放置新游戏按钮

    def new_game(self): # 3 游戏渲染
        # 6 取消任何未完成的延迟任务，避免干扰新游戏
        if self.pending_id:
            self.root.after_cancel(self.pending_id)
            self.pending_id = None
        self.pending = None

        total = self.rows * self.cols # 3 计算游戏板总按钮数
        pairs = total // 2 # 3 计算游戏板配对数
        icon_list = (self.fruits * (pairs // len(self.fruits) + 1))[:pairs] # 3 生成游戏板配对
        cards = icon_list*2 # 3 生成游戏板配对
        random.shuffle(cards) # 3 随机选择游戏板配对

        for row in range(self.rows): # 3 游戏板行
            for col in range(self.cols): # 3 游戏板列
                self.data[row][col] = cards[row*self.cols+col] # 3 设置游戏板数据
                self.buttons[row][col].config(text='？', state=tk.NORMAL) # 3 设置游戏板按钮文本
        self.first = None # 6 初始化第一次点击的按钮
        self.paired_count = 0 # 6 初始化成功配对数

    def on_click(self, r, c): # 4 游戏板按钮点击事件
        # 5 如果存在等待翻回的卡片对，立即取消并翻回
        if self.pending:
            # 5 取消延迟任务
            if self.pending_id:
                self.root.after_cancel(self.pending_id)
                self.pending_id = None
            # 5 立即翻回 pending 的卡片
            r1, c1, r2, c2 = self.pending
            self._reset_cards(r1, c1, r2, c2)   # 这个方法会设置 self.pending = None
            
        if self.first is None: # 4 如果是第一次点击
            self._reveal_card(r, c) # 4 揭示游戏板按钮
            self.first = (r, c) # 4 设置第一次点击的按钮
        else: # 4 如果是第二次点击
            r1, c1 = self.first # 4 获取第一次点击的按钮
            if (r1, c1) == (r, c): # 4 如果是第一次点击的按钮
                return
            self._reveal_card(r, c) # 4 揭示游戏板按钮
            if self.data[r1][c1] == self.data[r][c]: # 4 如果是配对
                self.buttons[r1][c1].config(state=tk.DISABLED) # 4 禁用游戏板按钮
                self.buttons[r][c].config(state=tk.DISABLED) # 4 禁用游戏板按钮
                self.first = None   # 4 重置第一次点击的按钮
                self.paired_count += 1 # 5 增加成功配对数
                # 5 如果全部配对成功
                if self.paired_count == self.total_pairs:   # 5 如果全部配对成功
                    tk.messagebox.showinfo("胜利", "恭喜你完成了所有配对！") # 5 显示胜利消息
                    self.root.destroy() # 5 销毁主窗口对象 
            else:
                # 4 配对失败，延迟翻回
                self.pending = (r1, c1, r, c) # 5 存储待翻回的卡片对
                # 5 延迟翻回游戏板按钮
                self.pending_id = self.root.after(800, self._reset_cards, r1, c1, r, c) # 5 延迟翻回游戏板按钮
                self.first = None # 5 重置第一次点击的按钮

    def _reveal_card(self, r, c): # 4 揭示游戏板按钮
        self.buttons[r][c].config(text=self.data[r][c], state=tk.DISABLED) # 4 揭示游戏板按钮

    def _reset_cards(self, r1, c1, r2, c2): # 4 重置游戏板按钮
        """将两张卡片翻回背面"""
        self.buttons[r1][c1].config(text='?', state=tk.NORMAL) # 4 重置游戏板按钮
        self.buttons[r2][c2].config(text='?', state=tk.NORMAL) # 4 重置游戏板按钮
        self.pending = None # 5 重置待翻回的卡片对
        self.pending_id = None # 5 重置 after 任务的 id，用于取消延迟任务

if __name__ == "__main__":  # 1 主函数入口
    root = tk.Tk()  # 1 创建主窗口对象
    game = MemoryGame(root) # 1 创建游戏对象
    root.mainloop() # 1 进入主事件循环
```

```python
    def start_timer(self):
```
