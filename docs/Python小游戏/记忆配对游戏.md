# 记忆配对游戏（tkinter 版）分步构建教程

本教程将带领你从零开始，使用 Python 的 tkinter 库逐步构建一个**记忆配对（翻牌配对）**游戏。最终游戏支持自定义行列数（如 4×8）、随机生成水果图标对、点击配对、延迟翻回、胜利检测等功能。

整个构建过程分为 **5 个阶段**，每个阶段在前一阶段基础上增加新功能，逻辑清晰，适合初学者或教学使用。

---

## 阶段 1：建立游戏窗口和基础框架

### 目标
创建一个空白窗口，并设置标题。

### 代码
```python
import tkinter as tk

root = tk.Tk()
root.title("记忆配对游戏")
root.mainloop()
```

### 讲解
- `tk.Tk()` 创建主窗口。
- `title()` 设置窗口标题。
- `mainloop()` 让窗口保持显示并等待用户操作（事件循环）。

---

## 阶段 2：创建按钮网格

### 目标
在窗口中生成一个 4 行 × 8 列的按钮网格，所有按钮显示问号 `?`。

### 代码（在 `mainloop` 之前添加）
```python
ROWS, COLS = 4, 8

frame = tk.Frame(root)
frame.pack()

buttons = [[None] * COLS for _ in range(ROWS)]

for r in range(ROWS):
    for c in range(COLS):
        btn = tk.Button(frame, text='?', width=4, height=2, font=('Arial', 20))
        btn.grid(row=r, column=c, padx=2, pady=2)
        buttons[r][c] = btn
```

### 讲解
- `Frame` 作为按钮容器，`pack()` 将其放入窗口。
- 二维列表 `buttons` 存储所有按钮对象，便于后续修改。
- `grid()` 将按钮排列成表格，`padx/pady` 增加间距。

---

## 阶段 3：生成随机卡片数据并绑定点击显示图标

### 目标
- 生成随机打乱的水果图标对（共 32 张，16 对）。
- 点击按钮时，将按钮文字临时显示为对应的水果图标。

### 代码（替换阶段2的简单按钮创建，并添加数据生成逻辑）
```python
import random   # 文件顶部

FRUITS = ['🍎', '🍌', '🍒', '🍇', '🥝', '🍊', '🍉', '🍓']

def create_shuffled_cards():
    total = ROWS * COLS          # 32
    pairs = total // 2           # 16
    # 从 FRUITS 中循环取，凑够 pairs 个图标
    icons = []
    while len(icons) < pairs:
        icons.extend(FRUITS)
    icons = icons[:pairs]
    # 每个图标出现两次并打乱
    cards = icons + icons
    random.shuffle(cards)
    # 转成二维列表
    return [cards[r*COLS:(r+1)*COLS] for r in range(ROWS)]

data = create_shuffled_cards()

def on_click(r, c):
    # 暂时只显示图标，不处理配对
    buttons[r][c].config(text=data[r][c])

# 创建按钮时绑定 command
for r in range(ROWS):
    for c in range(COLS):
        btn = tk.Button(frame, text='?', width=4, height=2, font=('Arial', 20),
                        command=lambda r=r, c=c: on_click(r, c))
        btn.grid(row=r, column=c, padx=2, pady=2)
        buttons[r][c] = btn
```

### 讲解
- `create_shuffled_cards` 自动适配任意偶数网格（例如 4×8）。
- `lambda r=r, c=c` 确保每个按钮记住自己的行列（避免闭包陷阱）。
- 点击按钮后，按钮文字会变成对应的水果，但还没有配对逻辑，可以随意点击。

## 阶段 4：实现配对逻辑（记录第一张/第二张，成功/失败，延迟翻回）

### 目标
- 记录用户第一次和第二次点击的卡片。
- 如果两张卡片图标相同，则永久保持翻开（禁用按钮）。
- 如果不同，等待 1 秒后自动翻回问号。
- 在动画期间禁止点击其他卡片。

### 代码（替换 `on_click` 函数，并添加状态变量和辅助函数）
```python
# 在 data 创建之后添加
state = [[False] * COLS for _ in range(ROWS)]   # True表示已配对
first = None       # 存储第一张卡片坐标
waiting = False    # 是否正在等待翻回动画

def update_button(r, c):
    """根据 state 更新按钮外观"""
    if state[r][c]:
        buttons[r][c].config(text=data[r][c], state=tk.DISABLED)
    else:
        buttons[r][c].config(text='?', state=tk.NORMAL)

def reset_cards(r1, c1, r2, c2):
    """延迟后翻回背面"""
    buttons[r1][c1].config(text='?', state=tk.NORMAL)
    buttons[r2][c2].config(text='?', state=tk.NORMAL)
    global waiting
    waiting = False

def on_click(r, c):
    global first, waiting
    if waiting or state[r][c]:
        return           # 动画中或已配对的卡片无法点击
    if first is None:
        # 翻开第一张
        buttons[r][c].config(text=data[r][c], state=tk.DISABLED)
        first = (r, c)
    else:
        r1, c1 = first
        if (r1, c1) == (r, c):
            return       # 同一张卡片无效
        # 翻开第二张
        buttons[r][c].config(text=data[r][c], state=tk.DISABLED)
        root.update()
        if data[r1][c1] == data[r][c]:
            # 配对成功
            state[r1][c1] = True
            state[r][c] = True
            update_button(r1, c1)
            update_button(r, c)
        else:
            # 配对失败，延迟翻回
            waiting = True
            root.after(1000, reset_cards, r1, c1, r, c)
        first = None

# 初始化所有按钮（在创建按钮后调用一次）
for r in range(ROWS):
    for c in range(COLS):
        update_button(r, c)
```

### 讲解
- `state` 记录已配对的卡片，这类卡片不可点击且永久显示图标。
- `waiting` 锁防止在延迟期间用户点击新卡片。
- `after(1000, ...)` 在 1 秒后调用 `reset_cards` 将两张卡片翻回问号。
- 配对成功后调用 `update_button` 更新按钮状态。

## 阶段 5：添加胜利检测和新游戏功能

### 目标
- 每次配对成功后检查是否所有卡片都已配对，若是则弹出胜利提示并结束游戏。
- 增加一个“新游戏”按钮，可以重新开始。

### 代码（在配对成功部分添加胜利检测，并增加重置方法）
```python
# 在配对成功的代码块中添加胜利检测
if data[r1][c1] == data[r][c]:
    state[r1][c1] = True
    state[r][c] = True
    update_button(r1, c1)
    update_button(r, c)
    # 胜利检测
    if all(state[row][col] for row in range(ROWS) for col in range(COLS)):
        tk.messagebox.showinfo("胜利", "恭喜你完成了所有配对！")
        root.destroy()   # 关闭游戏窗口

# 添加新游戏函数（可选）
def new_game():
    global data, state, first, waiting
    data = create_shuffled_cards()
    state = [[False] * COLS for _ in range(ROWS)]
    first = None
    waiting = False
    for r in range(ROWS):
        for c in range(COLS):
            update_button(r, c)

# 在窗口上添加一个按钮
reset_btn = tk.Button(root, text="新游戏", command=new_game)
reset_btn.pack()
```

### 讲解
- `all()` 检查二维列表中是否所有元素均为 `True`，是则弹出胜利对话框。
- `new_game` 重新生成卡片数据并重置所有状态，实现重玩功能。

## 最终完整代码（面向对象版）

将所有阶段整合并封装为类，即为下面完整的可运行游戏：

```python
import tkinter as tk
import random

class MemoryGame:
    def __init__(self, root, rows=4, cols=8, fruits=None):
        self.root = root
        self.rows = rows
        self.cols = cols
        self.fruits = fruits or ['🍎', '🍌', '🍒', '🍇', '🥝', '🍊', '🍉', '🍓']
        self.root.title("记忆配对 · 最终版")
        
        self.buttons = [[None] * cols for _ in range(rows)]
        self.data = [[0] * cols for _ in range(rows)]
        self.state = [[False] * cols for _ in range(rows)]
        self.first = None
        self.waiting = False
        
        self.create_board()
        self.new_game()
    
    def create_board(self):
        frame = tk.Frame(self.root)
        frame.pack()
        for r in range(self.rows):
            for c in range(self.cols):
                btn = tk.Button(frame, text='?', width=4, height=2,
                                font=('Arial', 20),
                                command=lambda r=r, c=c: self.on_click(r, c))
                btn.grid(row=r, column=c, padx=2, pady=2)
                self.buttons[r][c] = btn
        
        # 新游戏按钮
        reset_btn = tk.Button(self.root, text="新游戏", command=self.new_game)
        reset_btn.pack()
    
    def new_game(self):
        total = self.rows * self.cols
        pairs = total // 2
        icons = []
        while len(icons) < pairs:
            icons.extend(self.fruits)
        icons = icons[:pairs]
        cards = icons + icons
        random.shuffle(cards)
        
        for r in range(self.rows):
            for c in range(self.cols):
                self.data[r][c] = cards[r * self.cols + c]
                self.state[r][c] = False
                self.buttons[r][c].config(text='?', state=tk.NORMAL, bg='SystemButtonFace')
        
        self.first = None
        self.waiting = False
    
    def on_click(self, r, c):
        if self.waiting or self.state[r][c]:
            return
        if self.first is None:
            self.buttons[r][c].config(text=self.data[r][c], state=tk.DISABLED)
            self.first = (r, c)
        else:
            r1, c1 = self.first
            if (r1, c1) == (r, c):
                return
            self.buttons[r][c].config(text=self.data[r][c], state=tk.DISABLED)
            self.root.update()
            
            if self.data[r1][c1] == self.data[r][c]:
                self.state[r1][c1] = True
                self.state[r][c] = True
                self.buttons[r1][c1].config(state=tk.DISABLED)
                self.buttons[r][c].config(state=tk.DISABLED)
                self.first = None
                if all(self.state[row][col] for row in range(self.rows) for col in range(self.cols)):
                    tk.messagebox.showinfo("胜利", "恭喜你完成了所有配对！")
                    self.root.destroy()
            else:
                self.waiting = True
                self.root.after(1000, self.reset_cards, r1, c1, r, c)
                self.first = None
    
    def reset_cards(self, r1, c1, r2, c2):
        self.buttons[r1][c1].config(text='?', state=tk.NORMAL)
        self.buttons[r2][c2].config(text='?', state=tk.NORMAL)
        self.waiting = False

if __name__ == '__main__':
    root = tk.Tk()
    game = MemoryGame(root, rows=4, cols=8)
    root.mainloop()
```
