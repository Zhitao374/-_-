## 完整代码

```python
import requests
from bs4 import BeautifulSoup
import re
import json

HEADERS = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
    'cookie': ''   # 如有需要可填入
}

def get_songs(url):
    """获取排行榜歌曲列表（标题 + 详情页链接）"""
    resp = requests.get(url, headers=HEADERS, timeout=10)
    resp.encoding = 'utf-8'
    soup = BeautifulSoup(resp.text, 'html.parser')
    songs_li = soup.find('div', class_='pc_temp_songlist').find_all('li')
    songs = []
    for song in songs_li:
        song_info = song.find('a', class_='pc_temp_songname')
        songs.append({
            'title': song_info['title'].strip(),
            'href': song_info['href'].strip()
        })
    return songs

def get_song_hash(urls):
    """从详情页提取 hash 值，并获取播放地址"""
    for url in urls:
        pattern = r'dataFromSmarty\s*=\s*(\[.*?\]),'
        resp = requests.get(url['href'], headers=HEADERS, timeout=10)
        resp.encoding = 'utf-8'
        match = re.search(pattern, resp.text, re.DOTALL)
        if match:
            url['hash'] = json.loads(match.group(1))[0]["hash"]
            url['url'] = get_song_url(url)
        else:
            url['hash'] = None
            url['url'] = '未找到hash'
    return urls

def get_song_url(songInfo):
    """通过移动端API获取播放链接"""
    api_url = "http://m.kugou.com/app/i/getSongInfo.php"
    params = {
        'cmd': 'playInfo',
        'hash': songInfo['hash']
    }
    resp = requests.get(api_url, params=params, headers=HEADERS, timeout=10)
    data = resp.json()
    # 付费歌曲 backup_url 为空
    return "付费歌曲" if data.get('backup_url') == {} else data.get('backup_url', ['未知'])[0]

def main():
    rank_url = 'https://www.kugou.com/yy/rank/home/1-8888.html?from=rank'
    songs = get_songs(rank_url)
    song_urls = get_song_hash(songs[:10])   # 只取前10首做演示
    for s in song_urls:
        print(f"{s['title']} -> {s['url']}")

if __name__ == '__main__':
    main()
```

## 知识点总结

### 1. 网络请求（requests）
- `requests.get()` 发送 GET 请求，`headers` 模拟浏览器，`timeout` 设置超时。
- 设置 `resp.encoding = 'utf-8'` 避免中文乱码。
- `resp.json()` 将返回的 JSON 转为 Python 字典。

### 2. HTML解析（BeautifulSoup）
- `find()` 和 `find_all()` 按标签和类名查找元素。
- 通过 `tag['属性名']` 获取属性值。
- `.strip()` 去除文本首尾空白字符。

### 3. 正则表达式（re）
- `re.search(pattern, text, re.DOTALL)` —— `re.DOTALL` 使 `.` 可匹配换行符。
- `match.group(1)` 提取分组内容。

### 4. JSON处理（json）
- `json.loads()` 将 JSON 字符串解析为 Python 对象。

### 5. 流程控制
- 循环遍历列表，字典存储数据。
- 三元表达式简化条件赋值。

## 扩展知识

### 动态内容处理
- 网站数据可能由 JavaScript 动态加载，此时可直接寻找数据 API（如本例的 `getSongInfo.php`）。
- 也可使用 Selenium/Playwright 模拟浏览器。

### 反爬策略
- **User-Agent**：必须填写浏览器标识。
- **Cookie**：部分接口需携带登录凭证。
- **请求频率**：加入 `time.sleep()` 降低请求速度，避免被封 IP。
- **代理 IP**：应对 IP 封锁。

### 异常处理
- 实际开发应添加 `try-except` 处理网络错误、解析失败等。

### 数据持久化
- 可将结果保存为 CSV、JSON 或存入数据库。

## 注意事项

1. **仅供学习**：代码用于演示爬虫原理，不可用于商业或侵权用途。
2. **接口易变**：网站随时可能更新，代码需持续维护。
3. **付费限制**：付费歌曲无法获取播放链接。
4. **缺少容错**：示例代码未处理 `match` 为空等异常，生产环境需完善。
5. **尊重 robots.txt**：爬取前先查看网站协议。
